键盘配置器

触控板手感、键面、灯效预览；保存后生成 bbq10.conf / bbq10.keymap

说明

这些值写入 config/bbq10.conf，提交后 GitHub Actions 会重新编译固件。鼠标移动和滚动是两套参数，互不影响。

Blackberry：长按仍是 Command；单击切滚动，双击切方向键。Caps 只切大小写，不管滚动。

键面

字母层白字是字母，橙字是符号层（Alt 进入后输入）。符号层橙字是 Shift 上层，不是 Ctrl，也不能再打字母。功能层只显示已定义的键。

三路灯：上层 4 颗功能键共用一路；触控板中间一颗；字母区背光一路。

灯效

点某一行预览。选项会写入 conf；刷含新固件的 uf2 后键盘才会换成同样的闪法。

GitHub 直接读写

Token 只存在这台电脑的浏览器，请求只发到 api.github.com。不要发到聊天、不要写进仓库。

如何获取 GitHub Token
  1. 打开 创建 Fine-grained token （需先登录 GitHub）
  2. Token name 随便填，例如 q10-config；Expiration 自己选
  3. Resource owner 选拥有该仓库的 GitHub 账号（下面仓库链接里 github.com/ 后面第一段，你的用户名）
  4. Repository access 选 Only select repositories，只加链接里的那个仓库（仓库名）
  5. Permissions → Repository permissions → Contents 必须选 Read and write（选 Read-only 会推送失败）。改权限后要重新 Generate，旧 Token 不会自动升级
  6. 点 Generate token，立刻复制（只显示一次）
  7. 粘贴到下面的 Token 框

若出现 Resource not accessible by personal access token：Contents 不是 Read and write、没勾这个仓库，或改完权限仍在用旧 Token。公开库更省事：用 Classic token 只勾 public_repo。官方说明： Managing personal access tokens。

填写 GitHub 仓库地址后，会自动解析账号、仓库名和默认分支。
