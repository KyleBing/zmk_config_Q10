BlackBerry Q10 · ZMK

键盘配置器

触控板手感、键面、灯效预览；保存后生成 bbq10.conf / bbq10.keymap

说明

这些值写入 config/bbq10.conf，提交后 GitHub Actions 会重新编译固件。鼠标移动和滚动是两套参数，互不影响。

Blackberry：长按仍是 Command；单击切滚动，双击切方向键。Caps 只切大小写，不管滚动。

键面

点键盘上的键来改绑定。显示名可以和实际 ZMK 代码分开。

三路灯：上层 4 颗功能键共用一路；触控板中间一颗；字母区背光一路。

灯效

点某一行预览。选项会写入 conf；刷含新固件的 uf2 后键盘才会换成同样的闪法。

GitHub 直接读写

Token 只存在这台电脑的浏览器，请求只发到 api.github.com。不要发到聊天、不要写进仓库。

如何获取 GitHub Token
  1. 打开 创建 Fine-grained token （需先登录 GitHub）
  2. Token name 随便填，例如 q10-config；Expiration 自己选
  3. Resource owner 选 KyleBing
  4. Repository access 选 Only select repositories，只加 zmk_config_Q10
  5. Permissions → Repository permissions → Contents → Read and write
  6. 点 Generate token，立刻复制（只显示一次）
  7. 粘贴到下面的 Token 框

备用：Classic token 对公开库勾 public_repo 即可。官方说明见 Managing personal access tokens。
